# Pixel Cat Room

Затишна воксельна кімната з чорним котом, який у ній живе. Ізометричний діорамний
вигляд, фіксована камера, кіт ніколи не стоїть на місці: дихає, кліпає, веде головою
за курсором, вмивається, позіхає, дрімає, іноді зістрибує зі столу погуляти й
повертається назад.

Без збірки. Звичайні HTML/CSS/JS + three.js з CDN.

## Запуск локально

Потрібен будь-який статичний сервер (через `file://` ES-модулі не працюють):

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Деплой на GitHub Pages

1. Поклади вміст цієї папки в корінь репозиторію.
2. `git add . && git commit -m "pixel cat room" && git push`
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
4. Сайт буде за `https://НІК.github.io/РЕПО/`. Усі шляхи відносні, підпапка працює.

## Структура

```
index.html            розмітка, імпорт-мапа three.js
css/style.css         оформлення сторінки
js/
  main.js             сцена, камера, світло, склеювання всього
  i18n.js             словник UA/RU/EN — усі тексти тут
  ui.js               екран налаштування, перемикач мов, прихований рядок стану
  voxel.js            воксельний конструктор (InstancedMesh + м'яке затінення)
  room.js             кімната, меблі, джерела світла, сітка прохідності
  posters.js          плакати: піксельні заглушки або твої фото
  cat.js              кіт: іменовані вузли, які чекає контролер
  catController.js    мікрожиття й процедурні кліпи (чхання, вмивання, позіхання)
  behavior.js         машина станів: простій, прогулянки, смаколик, чхання
  pathfinding.js      A* по підлозі
  audio.js            завантаження і відтворення файлів з assets/sounds/
assets/
  manifest.json       що саме завантажувати (моделі, плакати, звуки)
  models/ posters/ sounds/
```

## Як підставити свої файли

Усе вмикається через `assets/manifest.json`. Поки поле порожнє — використовується
вбудована заглушка і **жодного зайвого запиту** в консоль не йде.

```json
{
  "models":  { "room": "room.glb", "cat": "cat.glb" },
  "posters": { "pyramids": "pyramids.jpg", "apple": "apple.png" },
  "sounds":  { "sneeze": "sneeze.mp3", "purr": "purr.mp3" }
}
```

- **Моделі** — поклади `.glb` у `assets/models/` і впиши ім'я файлу.
  Вимоги до вузлів і масштабу — у `MODELS.md`.
- **Плакати** — поклади зображення в `assets/posters/`. Ключі — це місця на стінах:
  `pyramids`, `doodles`, `flag`, `apple`, `moon`, `cookie`, `catphoto`, `strip`,
  `polaroids`. Картинки навмисно зменшуються і рендеряться з `NearestFilter`,
  тому дрібні деталі зникнуть — це задумано, кадруй крупно.
- **Звуки** — уже на місці в `assets/sounds/`. Нявкання, чхання і муркотіння —
  справжні записи (по кілька дублів на звук, програється випадковий), хрускіт і
  приземлення — поки синтезовані заглушки. Деталі — `SOUNDS.md`.

## Що на екрані

Над кімнатою — ім'я кота, перемикач мов, кнопка звуку і посилання «змінити кота».
Під кімнатою — рівно дві кнопки: **чхнути** і **смаколик**. Смаколик запускає цілу
сцену (стрибок зі столу → хода в найближчий до камери кут → помах лапою → хрускіт →
муркотіння → повернення на стіл), тому кнопка на цей час гасне. Текстових підписів
під кімнатою немає навмисно: рядок стану лишився тільки для скрінрідерів.

## Що де крутити

- Планування кімнати — `js/room.js`: координати меблів у вокселях, масив
  `OBSTACLES` (куди коту не можна), `pois` (куди він ходить гуляти).
- Характер — `js/behavior.js`: `IDLE_POOL` (що робить на столі і як довго),
  ймовірність прогулянки `0.3` у `planIdle()`, таймер чхання `this.sneezeTimer = 60`,
  нявкання `this.meowTimer = rand(15, 20)` і пауза після смаколика (`60`),
  ймовірність самостійного муркотіння `0.38` у `planIdle()`.
- Куди ходить гуляти — масив `pois` у `js/room.js`: `weight` задає, як часто кіт
  обирає місце (у килимка найбільша вага), `stay` — скільки там сидить, `face` —
  куди дивиться, коли прийшов.
- Рухи — `js/catController.js`: кліпи `sneeze`, `groom`, `yawn`, `stretch`, `wave`,
  `eat`, `purr`, `land`.
- Тексти — `js/i18n.js`. Щоб додати мову, скопіюй будь-який блок: перемикач
  будується з ключів словника сам.
- Камера — `js/main.js`, `viewSize` у `resize()` (більше = далі).

## Продуктивність

Кімната — один `InstancedMesh` (приховані воксели не створюються взагалі), кіт —
по одному на частину тіла. Одне джерело світла з тінями, `pixelRatio` обмежений 2.
Цільовий десктоп тримає 60 fps.

## Мобільні

Поки що десктоп. Верстка на флексах і одному `aspect-ratio` контейнері, камера
перераховується в `resize()` — адаптація зводиться до медіазапитів у `style.css`
і меншого `viewSize`.
